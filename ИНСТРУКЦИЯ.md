# Vega (Вега): инструкция для того, кто устанавливает

Vega — голосовой помощник для незрячего человека. Версия 0.3.0. Вега работает без интернета, кроме погоды, новостей и сайтов. Звук с микрофона никуда не отправляется.

Этот ZIP содержит **исходники**, а не готовый установщик. Инструкция по установке ниже относится к `Vega-Setup.exe`, который ещё нужно собрать на Windows по файлу `СБОРКА.txt` и испытать на целевом компьютере. Реальная работа на Windows с микрофоном, USB и CD/DVD пока не подтверждена.

## 1. Что нужно заранее

**Компьютер:** Windows 7 SP1, 8, 8.1, 10 или 11, обязательно 64-разрядная. Минимум i5 3-го поколения и 6 ГБ памяти.

**Windows 7, до установки:**
1. Проверить, что стоит SP1: Пуск → правой кнопкой «Компьютер» → Свойства.
2. Нужны обновления KB3063858 (или старое KB2533623) и KB2999226 (Universal CRT). Если Windows обновлялась после 2015 года, они уже есть. Проверка: Пуск → cmd → `wmic qfe get hotfixid | findstr "2533623 3063858 3125574 2999226"`. Установщик Веги сам скажет, если первого обновления нет.
3. Выставить правильные дату и время. С неправильной датой погода и новости не откроются.
4. Chrome 109. Это последняя версия для Windows 7, ставится автономным установщиком.

**Windows 10/11:** Параметры → Конфиденциальность → Микрофон: включить «Разрешить приложениям доступ к микрофону» и «Разрешить классическим приложениям». Без этого Вега не слышит.

**Микрофон:** подключить и проверить. Панель управления → Звук → Запись: нужное устройство должно быть «по умолчанию». Лучше гарнитура или настольный микрофон, а не встроенный в ноутбук рядом с динамиками.

**NVDA**, если человек им пользуется, ставить как обычно. Помощник сам глушит NVDA на время своих ответов.

## 2. Установка

1. Запустить `Vega-Setup.exe`. Права администратора не нужны, программа ставится в профиль пользователя.
2. Галочку «Запускать Вегу при входе в Windows» оставить включённой.
3. На Windows 7 установщик сам поставит русский голос RHVoice, если он есть в сборке. Если окно RHVoice появится, нажимать «Далее» до конца.
4. Больше ничего отвечать не нужно. Вега сама берёт микрофон Windows по умолчанию, сама выбирает голос (лёгкий голос Windows при памяти меньше 8 ГБ, иначе нейросетевой Piper) и сама определяет город по интернету для погоды и новостей.
5. После установки Вега запустится и скажет «Вега запускается, подождите», потом поздоровается: «Привет! Чем я могу помочь?» и 10 секунд ждёт команду без «Привет, Вега». На старом жёстком диске первый запуск занимает до минуты.

Другой город можно назвать голосом: «Привет, Вега», затем «мой город …».

Для помощника, который настраивает компьютер: ручная настройка (микрофон, голос, поисковик, сайты для открытия голосом) запускается из папки программы командой `VoiceAssistSetup.exe --setup`.

## 3. Расширение Chrome (один раз, обязательно для сайтов и YouTube)

Без расширения работают все команды, кроме чтения страниц, поиска на сайтах и управления видео.

1. В Chrome открыть адрес `chrome://extensions`.
2. Справа вверху включить «Режим разработчика».
3. Нажать «Загрузить распакованное расширение» и выбрать папку `%LOCALAPPDATA%\Programs\VoiceAssist\chrome_extension`. Путь можно вставить в адресную строку окна выбора папки.
4. Должна появиться карточка «Vega», ID `jdnfenolnkkdfhdphjapooponmobhjhb`. Режим разработчика оставить включённым.
5. Перезапустить Chrome. Проверка: открыть любой сайт и сказать «Привет, Вега», затем «что на странице».

Chrome при запуске может предлагать «Отключить расширения в режиме разработчика». Нажимать крестик, не «Отключить».

## 4. Проверка после установки (5 минут)

Каждый раз сначала сказать «Привет, Вега», дождаться «Привет! Чем я могу помочь?» и сказать команду:
1. «который час»: называет время.
2. «какая погода»: погода или просьба назвать город.
3. «открой блокнот», затем «напиши привет точка»: в Блокноте появляется «Привет.».
4. «закрой окно», затем «прочитай окно», затем «нажми не сохранять».
5. В Chrome: «найди на ютубе кино группа крови», потом «что нашлось», «воспроизведи первый», «пауза».
6. Вставить флешку: Вега сама говорит, что она подключена. Потом «что на флешке», «безопасно извлеки флешку».

Если что-то не так, сказать «Привет, Вега, сохрани отчёт для помощи». На рабочем столе появится файл `Vega-отчёт-….txt` с ошибками и последними командами. Продиктованный текст, заметки и напоминания туда не попадают, ключ связи с Chrome тоже.

## 5. Как говорить с Вегой

- Разговор начинается со слов **«Привет, Вега»**. Вега отвечает «Привет! Чем я могу помочь?» и 10 секунд ждёт команду.
- Можно сразу одной фразой: «Привет, Вега, который час».
- После ответа Вега ещё 15 секунд слушает продолжение без приветствия: «дальше», «да», «открой номер два», «подтверждаю удаление». Если не расслышала, скажет «Не поняла» и повторит услышанное. Потом звучит низкий короткий сигнал: Вега перестала слушать, нужно снова «Привет, Вега».
- «Спасибо» или «всё» заканчивает разговор сразу.
- Без «Привет, Вега» Вега ничего не выполняет, разговоры в комнате и телевизор не мешают.
- После команды раздаётся короткий щелчок: Вега услышала. Если действие долгое, она скажет «Секунду».
- Чтобы прервать длинный ответ или список, сказать «стоп», «остановись» или «Вега, замолчи».
- **«помоги»**: что можно сделать сейчас (подсказки зависят от того, что открыто). **«дальше»**: следующие.
- **«повтори»**: повторить последний ответ. **«Вега, замолчи»**: прервать речь. **«отмена»**: отменить то, что ждёт подтверждения.
- Опасные действия выполняются только после фразы подтверждения, которую Вега назовёт сама. Подтверждение действует одну минуту.
- Списки читаются по пять пунктов: «дальше» читает следующие. Пункт открывается по номеру: «открой номер два», «номер два» или «второй». Так же работают новости, окна, ролики и фильмы.

## 6. Все команды

Перед командами сказать «Привет, Вега» (или говорить их сразу после предыдущего ответа). Варианты через «/» равнозначны. «…» означает любые слова.

### Общие
| Фраза | Что делает |

| помоги / что ты умеешь / какие команды доступны | Подсказки по текущей ситуации |

## 7. Если что-то не работает

| Признак | Что сделать |
|---|---|
| Молчит после запуска | Подождать минуту (старый диск). Потом проверить, что VoiceAssist.exe (это программа Веги) есть в Диспетчере задач. Ошибка записана в `%APPDATA%\VoiceAssist\last-error.log` |
| «Микрофон недоступен» | Проверить подключение и устройство записи по умолчанию; в Windows 10/11 разрешение микрофона. Помощник сам повторяет попытки |
| Не отвечает на «Привет, Вега» или не понимает команды | Говорить ровно и не слишком быстро. Микрофон ближе, телевизор тише. Сделать нужный микрофон устройством записи по умолчанию в Windows |
| Голос слишком быстрый/медленный | «говори медленнее» / «говори быстрее» |
| Помощник и NVDA говорят одновременно | Проверить, что в папке программы есть `nvdaControllerClient64.dll` |
| «Нет связи с сервисом погоды» | Интернет, дата и время на компьютере |
| «Chrome с расширением Vega не отвечает» | Открыть Chrome. Если не помогло: раздел 3, расширение выключено или Chrome не перезапущен |
| Тормозит компьютер | Закрыть лишние вкладки Chrome. В ручной настройке (`VoiceAssistSetup.exe --setup`) выбрать голос Windows |

**Файлы Веги.** Программа: `%LOCALAPPDATA%\Programs\VoiceAssist`. Данные: `%APPDATA%\VoiceAssist` (`settings.json` настройки, `personal.json` заметки и напоминания, `sites.json` сайты, `commands.log` журнал команд, `last-error.log` ошибки). При удалении программы данные остаются.

**Удаление:** Пуск → Vega → «Удалить Vega».
