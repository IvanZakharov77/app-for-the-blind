## Голосовые команды
- Числа словами, как их пишет Vosk: «поставь таймер на пять минут», «на минуту», «на полчаса», «на полторы минуты»; «напомни через десять минут …», «через час …»; «сколько будет двенадцать плюс семь», «переведи пять километров в метры». Текст заметок и напоминаний не переписывается в цифры. Новый модуль `voiceassist/numbers.py`.
- Синонимы: «который сейчас час», «сколько времени», «какое сейчас время», «какое число», «какая дата»; «установи/заведи таймер»; «умножь на», «раздели/подели на».
- Справка больше не предлагает недостижимое голосом: примеры даны словами, вместо «Открой HDRezka» — первое сохранённое русское название сайта. Новая команда «Какие сайты сохранены?».

## Сайты и Chrome
- Названия сайтов нормализуются как голосовые команды («ХД-Резка» = «хд резка»). Для старой записи `hdrezka` работают «хдрезка», «хд резка», «эйч ди резка», «резка». `--set-site` предупреждает, если название нельзя произнести.
- Подтверждение загрузки страницы больше не ломается из-за `/` в конце, `www.` и перехода http→https.
- В расширение добавлен постоянный ключ: ID всегда `jdnfenolnkkdfhdphjapooponmobhjhb` (`chrome_extension/EXTENSION_ID.txt`).

## Надёжность голосового режима
- Любая ошибка старта (микрофон, модель Vosk, синтез) пишется в `last-error.log` и даёт сигнал ошибки; раньше часть ошибок закрывала программу молча.
- Сбой микрофона во время работы больше не завершает программу: лог, сигнал, фраза «Микрофон недоступен…», повторное открытие с паузой до минуты, затем «Микрофон снова работает. Помощник готов.»
- Журнал ошибок дописывается (до 16 КБ), а не перезаписывается.
- Защита от второго экземпляра (мьютекс Windows), чтобы команды не выполнялись дважды. Новый модуль `voiceassist/instance.py`.
- Отключены системные окна «Вставьте диск» для пустых картридеров (`SetErrorMode`).
- Русский голос ищется по языку SAPI (0x419), что находит RHVoice на Windows 7. Новые параметры `--list-tts-voices` и `--set-tts-voice ИМЯ`.

## USB-копирование
- Объём озвучивается по-человечески («14 гигабайт», «3 мегабайта»), диски называются буквой и меткой («E, «Фото»»).
- Служебные папки Windows в корне (`System Volume Information`, `$RECYCLE.BIN`, `RECYCLER`, `FOUND.000`) не копируются.
- Каждый файл сбрасывается на носитель (`fsync`) до проверки, чтобы «завершено и проверено» не звучало, пока данные в кэше.
- Учтён лимит 2 ГБ для FAT (FAT16).

## Второй блок: запись CD/DVD, система, окна, будильник
Тесты: 145, все проходят на Python 3.10, 3.13 и 3.8.

### Запись CD/DVD (`voiceassist/optical_burn.py`)
- «Помощник, запиши на диск папку фото с моря» → поиск папки по названию в текущей папке, папке пользователя и на флешках; «документы», «рабочий стол», «музыка», «видео», «загрузки», «фото/изображения» понимаются как стандартные папки Windows.
- Проверка: записывающий привод, пустой носитель, ёмкость с запасом 20 МБ; озвучивается план (папка, привод, число файлов, объём из ёмкости). Нужна фраза «подтверждаю запись на диск».
- Перед записью заново проверяются содержимое папки и наличие пустого диска. Запись через IMAPI 2 (ISO 9660 + Joliet + UDF, для файлов от 4 ГБ — только UDF), диск закрывается, чтобы читался везде.
- Прогресс: «сколько осталось записывать», объявления 25/50/75 %. Во время прожига отмена честно отказывает (остановка испортит диск); до подтверждения план отменяется.
- После записи каждый файл читается с диска и сверяется по SHA-256. «Диск записан и проверен» звучит только при полном совпадении.
- Проверено имитацией привода; на настоящем приводе и Windows не испытано.

### Система и окна (`voiceassist/system.py`, только ctypes, без новых пакетов)
- «Какой заряд батареи», «есть ли интернет», «громче / тише / выключи звук».
- «Выключи компьютер», «перезагрузи компьютер» — только после отдельной фразы «подтверждаю выключение / перезагрузку» в течение минуты; выключение через 30 секунд, «отмени выключение» отменяет.
- «Открой блокнот / калькулятор / проводник / паинт / ворд / эксель / диспетчер задач / панель управления / экранный диктор / нвда» — успех засчитывается, только когда появилось новое окно.
- «Какие окна открыты», «переключись на окно два» или «на окно блокнот», «какое окно активно», «закрой окно» (если программа спрашивает о сохранении, помощник так и говорит).

### Личные функции
- Будильник: «поставь будильник на семь тридцать», «разбуди меня в восемь вечера» (хранится как напоминание, переживает перезапуск, но звучит только при запущенном помощнике).
- «Сколько осталось на таймере», «отмени таймер».
- «Удали последнюю заметку», «удали все заметки» — только после «подтверждаю удаление».
- Справка и «все категории» перечисляют новые команды; Windows-команды предлагаются только на Windows.

### Слабое железо
- При старте сначала включается голос и звучит «Помощник запускается, подождите», затем грузится модель Vosk (на старом HDD это может занять десятки секунд).
- Новые функции не добавили зависимостей и фоновых процессов; всё работает по запросу.

## Третий блок: Chrome и YouTube, окна, файлы, погода и новости, голос, установщик
Тесты: 195 на Python 3.8 и 3.13, плюс 15 проверок расширения в настоящем Chromium и сквозной тест «помощник ⇄ мост ⇄ Chrome».

### Chrome, страницы, фильмы и YouTube (расширение 0.2.0 + `browser_bridge.py`, `browser_commands.py`, `browser_routes.py`)
- Связь: помощник слушает только 127.0.0.1 со случайным ключом; Native Messaging host пропускает лишь операции из белого списка.
- Вкладки: новая/закрой/следующая/предыдущая, «перейди на вкладку три», «какие вкладки открыты»; назад/вперёд/обнови; история, загрузки, закладки; «добавь в закладки»; «закрой хром».
- Страница: «что на странице», «прочитай заголовки/ссылки/кнопки/поля» по пять, «дальше», «открой третью ссылку», «нажми вторую кнопку»; «прочитай текст», «продолжи чтение»; «найди на странице …»; прокрутка; «найди в интернете …» (Яндекс по умолчанию).
- YouTube: «найди на ютубе кино группа крови», «найди песню …», «включи музыку …» → «что нашлось» (название, канал, длительность) → «воспроизведи второй», «второй номер по списку» или «воспроизведи Кукушку» по названию. «Воспроизведи …» без списка сразу ищет на YouTube.
- Фильмы (HDRezka и похожие): «какие фильмы здесь есть», «найди фильм …», «открой второй фильм», «расскажи описание», «вернись к списку», «следующая серия». Если на странице нет поиска, «найди фильм» ищет на YouTube.
- Видео: пауза/продолжи/с начала, «вперёд на тридцать секунд», «назад на минуту», громче/тише/без звука видео, полный экран, «пропусти рекламу», «что с видео». Результат проверяется по состоянию плеера: если видео не пошло, помощник так и говорит.

### Окна программ (`window_ui.py`): UI Automation через comtypes, иначе Win32
- «Прочитай окно / сообщение» читает текст диалога и кнопки, например «Сохранить изменения?».
- «Что можно нажать», «какие здесь кнопки / поля / флажки», «нажми второй», «нажми кнопку не сохранять».
- Кнопки со словами «удалить / форматировать / стереть / очистить» нажимаются только после «подтверждаю нажатие».
- «Сверни окно», «разверни окно», «сверни все окна». Если впереди Chrome, «какие здесь кнопки» читает кнопки страницы.

### Файлы, флешки, CD/DVD (`file_browser.py`, `file_routes.py`)
- «Открой документы / загрузки / рабочий стол / музыку / мои видео», «что в папке», «следующие файлы», «открой третий», «открой файл …», «выйди из папки», «какая папка открыта».
- «Создай папку …»; «найди фотографии / видео / музыку / документы / книги», «найди файл …». Поиск ограничен по глубине, числу папок и 3 секундам, чтобы не мучить HDD.
- «Переименуй второй в Отпуск» (расширение сохраняется), «удали файл …» (в корзину; на флешке предупреждает, что навсегда), «скопируй третий на первую флешку», «скопируй фотографии на флешку», «перемести … на рабочий стол». Каждое действие только после своей фразы подтверждения. Ничего не перезаписывается, копия сверяется по SHA-256, место и FAT32 проверяются заранее.
- Программы и сценарии (.exe, .bat, .vbs и др.) открываются только после «подтверждаю запуск».
- «Сколько свободного места», «сколько места на первой флешке», «что на второй флешке», «безопасно извлеки первую флешку» (не выйдет, пока на флешке открыты файлы), «что на диске» и «сколько места на диске» для CD/DVD.
- «Отмена» отменяет любое ожидающее подтверждения действие.

### Погода, новости, город (`online.py`)
- «Какая погода», «погода на завтра», «погода в Казани». Источник — Open-Meteo: бесплатно, без ключа, без браузера. В ответе названы источник и время данных.
- «Какие новости» работают без настройки (Google Новости, по-русски). «Местные новости» и «новости Саратова» дают свежие статьи о городе за 2 дня. «Прочитай новость номер два».
- Город: «мой город Казань», или помощник сам предлагает город по интернет-подключению и сохраняет его только после «да, это мой город».
- Для Windows 7 с устаревшими сертификатами в сборку добавлен certifi. Без интернета помощник прямо говорит, что связи нет (ожидание не больше 8 секунд).

### Голос и речь
- Ответы звучат по-человечески. Раньше было «Ожидайте, идёт выполнение команды. Команда «который час» выполнена. По часам…», теперь «По часам компьютера сейчас 14:05.»
- Вместо фразы «ожидайте» звучит короткий щелчок; «Секунду» говорится, только если действие длится больше полутора секунд. Ошибки начинаются с «Не получилось», непроверенные действия так и названы.
- Естественный нейросетевой голос Piper (офлайн, бесплатно; русские голоса Ирина, Денис и др.) работает с загруженной моделью без задержек на каждую фразу. Если Piper не запустился (например, на конкретной Windows 7), помощник сам переходит на голос Windows (RHVoice) и пишет причину в журнал.
- «Говори медленнее / быстрее / обычно», «голос громче / тише» сохраняются в `settings.json`.
- Перед своей речью помощник останавливает речь NVDA, если рядом лежит nvdaControllerClient64.dll.
- Таймеры и напоминания подают короткий звук. Напоминания, срок которых прошёл при выключенном помощнике, называются пропущенными с датой и временем. «Какие напоминания» называет время; «удали напоминание номер два» удаляет только после подтверждения.
- Конвертации: длина, масса, время, объём («три часа в минуты», «пятьсот граммов в килограммы»).

### Настройка и установка
- `settings.json`: микрофон, скорость и громкость голоса, движок голоса, поисковик, город, источник новостей. Неверные значения заменяются обычными, и помощник об этом говорит.
- `VoiceAssistSetup.exe --setup`: текстовый мастер для близкого человека (микрофон, голос, поисковик, город, новости, сайты, автозапуск); у каждого вопроса есть значение по умолчанию.
- `installer/VoiceAssist.iss` (Inno Setup 6): один файл установки без прав администратора, Windows 7 SP1+ x64. Ставит программу, модель Vosk, Piper с голосом, RHVoice (если положен), связь с Chrome, автозапуск, ярлыки; есть удаление. `build-windows.cmd` скачивает модель и Piper сам и собирает установщик. Сторонние компоненты и лицензии: `installer/THIRD-PARTY.md`.
- «Открой настройки»: на Windows 10/11 это «Параметры», на Windows 7 — Панель управления.

## Четвёртый блок: подготовка к релизу

### Клавиши, меню, ввод текста (`core.py`, `system.py`, `window_ui.py`, `numbers.py`)
- «Напиши / напечатай / введи …» печатает в поле под фокусом через SendInput (Юникод, любая раскладка). Знаки препинания словами: «запятая», «точка», «вопросительный знак», «новая строка» и др. После точки заглавная буква. Если под фокусом кнопка или ссылка, помощник не печатает, а говорит, что там.
- «Прочитай поле / где фокус», «следующий / предыдущий пункт» (стрелки), «следующий / предыдущий элемент» (Tab), «выбери / нажми ввод», «нажми пробел», «нажми эскейп / закрой меню», «открой меню», «открой меню файл», «контекстное меню», «сотри букву / слово», «очисти поле» (после «да»). После перехода помощник читает новый элемент под фокусом.

### Переспрос для заметок и напоминаний
- Текст, услышанный Vosk, повторяется перед сохранением: «Записать заметку: купить хлеб? Скажите: да или нет.» «Нет» ничего не сохраняет.

### Продолжение копирования (`files.py`, `file_browser.py`, `usb_copy.py`)
- Незаконченное копирование (файлы, папки, «всё с первой флешки на вторую») записывается в `%APPDATA%\VoiceAssist\copy-journal.json`. После выдернутой флешки, сбоя или перезапуска помощник сам напоминает и по «продолжи копирование» докопирует. Уже скопированные файлы сверяются по SHA-256 и не копируются заново. Оборванный файл копируется заново. Перемещение удаляет оригинал только после полной проверенной копии. «Забудь копирование» убирает напоминание.

### Отчёт для помощи (`diagnostics.py`)
- «Сохрани отчёт для помощи» кладёт на рабочий стол `VoiceAssist-отчёт-ДАТА.txt`. В нём версия, Windows, память, место, голос, настройки, последние ошибки и 200 последних команд с ответами. Журнал команд `commands.log` ограничен 256 КБ. Продиктованный текст, заметки и напоминания в журнал не пишутся, ключ связи с Chrome в отчёт не попадает.

### Легче для слабого компьютера
- Голос «автоматически» включает Piper только при 8 ГБ памяти и больше. На 6 ГБ звучит RHVoice (около 30 МБ вместо 150 МБ). Piper можно выбрать в настройке принудительно.

### Сборка и установщик
- `VoiceAssist.iss` сохранён в UTF-8 с BOM: без этого Inno Setup портил русские надписи.
- Установщик копирует полные папки VoiceAssistSetup и VoiceAssistNativeHost (раньше только .exe без их библиотек, они бы не запустились).
- PyInstaller получает скрытые импорты драйвера SAPI (pyttsx3) и библиотеки Vosk.
- В установку добавлена `ИНСТРУКЦИЯ.txt` и ярлык «Инструкция VoiceAssist» в меню Пуск.

### Имя Vega и разговор «Привет, Вега» (`speech.py`)
- Помощника зовут Vega (Вега): международное имя для будущих языков. Внутренние имена файлов и папок (VoiceAssist.exe, `%APPDATA%\VoiceAssist`) не менялись, чтобы не ломать установленное.
- Разговор: «Привет, Вега» → «Привет! Чем я могу помочь?» → команда. Можно одной фразой: «Привет, Вега, который час». Команду Вега ждёт 8 секунд; после ответа ещё 6 секунд слушает продолжение без приветствия («дальше», «да», «открой второй»). Непонятная фраза в это время (телевизор, разговор) молча пропускается. «Спасибо» и «всё» заканчивают разговор. Окончание слушания отмечается низким коротким сигналом.
- Прервать речь: «Вега, замолчи». Одиночное «замолчи» не останавливает, потому что микрофон слышит и саму Вегу.
- Установщик, ярлыки, расширение Chrome и отчёт называются Vega; файл установки `Vega-Setup.exe`.
- Не проверено: есть ли слово «вега» в словаре малой русской модели Vosk. Принимаются варианты «вега», «века», «вегу», «веге».

### Инструкция
- `ИНСТРУКЦИЯ.md`: подготовка Windows 7/10/11, установка, расширение Chrome, проверка за 5 минут, все команды по разделам, что делать при неполадках.
