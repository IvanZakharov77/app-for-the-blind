# План реализации

Основа — [VoiceAssist-ТЗ.md](VoiceAssist-ТЗ.md). Порядок выбран так, чтобы каждый этап давал проверяемый результат.

1. Совместимость: Python 3.8 для Windows 7, проверка Windows x64 и Service Pack 1; допуск Windows 10 начиная с build 10240 и Windows 11 с build 22000 как разных семейств, отдельная проверка версий Chrome и зависимостей. Зафиксировать ограничения.
2. Офлайн-ядро: каталог намерений и синонимов, диалоговый контекст, справка, проверяемые итоги, системные часы и базовые операции Windows. Проверить тестами без микрофона.
   Локальное расширение ядра: таймеры, напоминания, заметки, ограниченные вычисления и конвертации; хранить пользовательские данные локально, не сканировать диск постоянно.
3. Речь: адаптер локального распознавания и синтеза, состояние готовности, безопасный запуск после входа в Windows. Проверить на реальном Windows и микрофоне.
4. Chrome: запуск и управление базовыми вкладками; расширение и Native Messaging для чтения страниц и плеера только после проверки совместимости.
5. USB и файлы: обнаружение, обзор, копирование с планом, подтверждением и проверкой результата. Проверить отключение устройства, FAT32 и восстановление.
6. Сборка и приёмка: отдельные Windows-сборки и испытания на Windows 7/10/11 x64; измерения на старом ноутбуке.

Критический риск: тесты на macOS не подтверждают совместимость с Windows, Vosk/RHVoice, конкретными версиями Chrome или сайтами.
