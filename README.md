# Vega (Вега)

Имя программы — Vega, внутреннее название проекта и файлов — VoiceAssist.

**Статус этого архива:** здесь только исходники и сценарий сборки. Готового `Vega-Setup.exe`, Windows EXE, модели Vosk и файлов голосов внутри нет. Установщик можно получить только после успешного запуска `build-windows.cmd` на Windows с доступом к нужным компонентам. На реальной Windows программа, установщик, микрофон, два USB-накопителя и CD/DVD-привод пока не испытаны; до этих проверок архив не является готовой поставкой для незрячего пользователя.

Сценарий сборки теперь останавливается, если не удалось получить ни полный голос Piper, ни предоставленный установщик RHVoice. После сборки он проверяет запуск консольного EXE и наличие итогового `Vega-Setup.exe`. Эти проверки ещё требуется выполнить на Windows.


Бесплатный локальный голосовой помощник для незрячего пользователя Windows 7 SP1 / 10 / 11 x64. Работает на слабых компьютерах (цель — i5 3-го поколения, 6 ГБ DDR3, HDD). Речь распознаётся офлайн (Vosk), голос — офлайн (Piper или RHVoice/SAPI). Звук никуда не отправляется.

Разговор начинается с «Привет, Вега» или «Вега». После отдельного обращения звучит короткий сигнал готовности, и Вега 10 секунд ждёт начала команды. Можно сразу одной фразой: «Привет, Вега, который час»; ожидать сигнала не нужно. Каждая следующая команда также начинается с обращения. При запуске приложения звучит голосовое приветствие. Главное: «помоги» называет, что можно сделать сейчас; «повтори»; «Вега, замолчи»; «отмена».

Что умеет:
- **Время, таймеры, будильник, напоминания, заметки, счёт и перевод единиц.**
- **Погода и новости.** Работают без браузера и настройки; местные новости идут по городу пользователя.
- **Компьютер.** Громкость, батарея, интернет, свободное место, выключение (только с подтверждением), программы, окна. Помощник читает диалоги и нажимает кнопки в них, ходит по спискам и меню, печатает продиктованный текст в любое поле.
- **Файлы.** Папки, поиск фото, видео и документов, переименование, удаление в корзину, копирование и перенос. Каждое изменение выполняется после отдельной фразы подтверждения. Прерванное копирование докопируется после перезапуска.
- **Флешки.** Список, место, содержимое, копирование всего с первой на вторую, безопасное извлечение.
- **CD/DVD.** Запись папки с проверкой каждого файла после прожига, содержимое диска, свободное место.
- **Chrome.** Вкладки, чтение страниц по пять элементов, поиск в интернете, сайты по сохранённым названиям, каталоги фильмов.
- **YouTube и видео.** «Найди на ютубе …», «что нашлось», «воспроизведи второй» или по названию; пауза, перемотка, громкость, следующая серия.

**Установка после успешной сборки и проверки на Windows.** Запустить полученный `Vega-Setup.exe`: права администратора по замыслу установщика не нужны. В конце должен открыться мастер настройки для близкого человека: микрофон, голос, город, новости, сайты. Расширение Chrome подключается один раз вручную, шаги описаны в ИНСТРУКЦИЯ.md. Если что-то не работает: «Привет, Вега, сохрани отчёт для помощи».

**Для разработчика.**
- Сборка (по шагам для неспециалиста: `СБОРКА.txt`): на любой Windows 7 SP1/8.1/10/11 x64 запустить `build-windows.cmd`. Python 3.8.10 и Inno Setup 6.2.2 скрипт поставит сам в `tools\`, результат `installer\Output\Vega-Setup.exe`.
- Тесты на любой ОС: `python -m unittest discover -s tests`.
- Проверка расширения в Chromium (Node + Playwright): `node tests_browser/test_page.mjs` и `python tests_browser/e2e_bridge.py`.
- Текстовый режим без звука: `python -m voiceassist`. Голосовой: `python -m voiceassist --voice --model ПАПКА_МОДЕЛИ`.

Статус: вся логика покрыта тестами, расширение проверено в настоящем Chromium. **На реальной Windows программа ещё не испытывалась.** Перед передачей пользователю нужен прогон по чек-листу из COMPATIBILITY.md.
