# Совместимость, установка и проверка на Windows

Статус: в независимой проверке этого архива 13.10.2026 прошли 222 теста на macOS с Python 3.14.5; проверка синтаксиса 65 Python-файлов с режимом Python 3.8 и синтаксиса JavaScript тоже прошла. Это не проверка выполнения на Python 3.8. Ранее заявлены испытания расширения в Chromium и сквозной тест моста «помощник ⇄ Chrome»; в этой проверке они повторно не запускались. **В архиве нет собранного EXE или установщика; Windows-сборки и испытания на реальном железе не проводились.** Код Windows-only (ctypes, IMAPI, UI Automation, SAPI, winsound) проверен только имитацией.

| Платформа | Статус | Особенности |
|---|---|---|
| Windows 7 SP1 x64 | Поддерживается | Python 3.8, Chrome 109 (последний для Windows 7). Своего русского голоса нет: ставится RHVoice. Для HTTPS используется certifi. «Открой настройки» открывает Панель управления |
| Windows 8 / 8.1 x64 | Разрешена с 0.3.3, испытывается | До 0.3.3 Вега на Windows 8 молча не запускалась (проверка версии), найдено на ноутбуке Ivan 2026-10-14 |
| Windows 10 / 11 x64 | Поддерживается | Голоса OneCore (Irina, Pavel) через SAPI5 обычно не видны. Используются Piper или RHVoice |
| 32-разрядная Windows | Нет | Vosk и Piper собираются только под x64 |

## Слабое железо (i5 3-го поколения, 6 ГБ DDR3, HDD)
- Всё работает по запросу: фонового сканирования дисков нет, флешки проверяются раз в 10 секунд, поиск файлов ограничен 3 секундами.
- При старте сначала звучит «Помощник запускается, подождите», потом загружается модель Vosk. С HDD это занимает десятки секунд.
- Память (оценка, замерить на целевом ноутбуке): малая модель Vosk около 300 МБ, Python около 60 МБ, RHVoice 20–40 МБ, Piper 120–180 МБ. Итого 350–450 МБ с голосом Windows, 500–600 МБ с Piper. Поэтому при «автоматическом» голосе Piper включается только на компьютере с 8 ГБ и больше.
- Piper синтезирует быстрее реального времени на процессорах с AVX (Ivy Bridge его поддерживает). Модель загружается один раз, а не на каждую фразу.

## Установка
1. Собрать на любом компьютере с Windows 7 SP1, 8.1, 10 или 11 x64 и интернетом: распаковать архив и запустить `build-windows.cmd`. Скрипт сам скачает и поставит в папку `tools\` (без прав администратора) Python 3.8.10 и Inno Setup 6.2.2, затем пакеты, модель Vosk и Piper с голосом «Ирина», прогонит тесты и соберёт `installer\Output\Vega-Setup.exe`. На Windows 7 нужно обновление KB3063858 (или KB2533623), без него Python 3.8 не запускается; скрипт предупредит. Если Python не скачался (старый Windows 7 без TLS 1.2), скачать `python-3.8.10-amd64.exe` вручную в папку `tools\` и запустить скрипт снова. RHVoice для Windows 7 и nvdaControllerClient64.dll положить в `third_party\` вручную, см. `installer/THIRD-PARTY.md`.
2. На компьютере пользователя запустить `Vega-Setup.exe`. Установка идёт в профиль пользователя без прав администратора. Установщик ставит RHVoice (если он в сборке), регистрирует связь с Chrome, по желанию включает автозапуск, запускает мастер настройки и самого помощника.
3. Подробная инструкция для устанавливающего, со всеми командами: `ИНСТРУКЦИЯ.md` (в установке `ИНСТРУКЦИЯ.txt`, ярлык в Пуске). Расширение Chrome, один раз: открыть `chrome://extensions`, включить «Режим разработчика», нажать «Загрузить распакованное расширение» и выбрать `%LOCALAPPDATA%\Programs\VoiceAssist\chrome_extension`. ID всегда `jdnfenolnkkdfhdphjapooponmobhjhb`. Chrome не позволяет программам ставить расширения молча, поэтому этот шаг делает близкий человек.
4. Удаление: «Пуск → Vega → Удалить Vega». Настройки и заметки остаются в `%APPDATA%\VoiceAssist`.

Мастер настройки можно запустить снова: «Пуск → Vega → Настройка Vega» (`VoiceAssistSetup.exe --setup`). Остальные параметры командной строки прежние: `--set-site`, `--list-tts-voices`, `--set-tts-voice`, `--install-autostart`, `--register-extension-id`.

Файлы пользователя в `%APPDATA%\VoiceAssist`: `settings.json`, `personal.json` (заметки, напоминания), `sites.json`, `bridge.json` (порт и ключ связи с Chrome), `last-error.log`, `commands.log` (журнал команд без продиктованного текста), `copy-journal.json` (незаконченное копирование).

## Чек-лист испытаний (каждую ОС)
1. **Голос.** Piper говорит. Переименовать папку `piper`: помощник должен сам перейти на RHVoice и записать причину в `last-error.log`. «Говори быстрее», «голос тише» должны сохраниться после перезапуска.
2. **Распознавание.** Слышит ли Vosk «Привет, Вега» с первого раза (слово «вега» должно быть в словаре модели; если модель пишет его иначе, добавить вариант в `NAME_VARIANTS` в `speech.py`). Ложные срабатывания от телевизора. Работает ли «Вега, замолчи» во время ответа. Продолжение без приветствия в течение 6 секунд и низкий сигнал после.
3. **NVDA.** С nvdaControllerClient64.dll речь NVDA обрывается, когда начинает говорить помощник.
4. **Погода и новости.** «Какая погода», «мой город …», «местные новости». На Windows 7 без обновлений проверить HTTPS. Отключить сеть: помощник должен сказать, что связи нет.
5. **Chrome.** Сначала новый Chrome, потом 109 на Windows 7: «что на странице», «найди на ютубе …», «что нашлось», «воспроизведи второй», «пауза», «вперёд на минуту», HDRezka «какие фильмы здесь есть».
6. **Окна.** Блокнот с несохранённым текстом: «закрой окно», «прочитай окно», «нажми не сохранять». Проверить UI Automation (comtypes) и запасной Win32-путь.
7. **Файлы и флешки.** «Открой документы», «найди фотографии», «скопируй фотографии на флешку», «удали файл …» (в корзину), «безопасно извлеки первую флешку» с открытым и закрытым файлом. Две флешки: «скопируй всё с первой на вторую». Флешка FAT32 и файл больше 4 ГБ.
8. **CD/DVD.** «Запиши на диск папку …», «сколько осталось записывать», проверка после прожига, «что на диске».
9. **Автозапуск, второй экземпляр, сон и пробуждение, отключение микрофона.**
10. **Ресурсы.** Память и время старта на i5-3xxx / 6 ГБ / HDD.
11. **Клавиши и ввод.** Блокнот: «напиши привет запятая как дела вопросительный знак». Меню Блокнота: «открой меню файл», «следующий пункт», «выбери». Диалог «Сохранить как»: «следующий элемент», «напиши письмо», «нажми ввод».
12. **Докопирование.** Начать копирование большой папки на флешку, выдернуть флешку, вставить обратно, «продолжи копирование». То же с перезапуском помощника.
13. **Отчёт.** «Сохрани отчёт для помощи»: файл на рабочем столе открывается в Блокноте без кракозябр.
14. **Сборка.** Установщик показывает русские надписи правильно; VoiceAssistSetup.exe и VoiceAssistNativeHost.exe из папки программы запускаются.
